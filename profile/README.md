# BOLT Association

**BOLT** (Bitcoin Original Layer-1 Token Protocol) is a token protocol that runs entirely in Bitcoin script on BSV:
every transfer is enforced by the token's own covenant, and a token's provenance is verified from two transactions,
at any depth of its history.

- **b017**, the TypeScript library: [npm package](https://www.npmjs.com/package/b017) ([repository](https://github.com/BOLT-Association/b017))
- **Website:** [boltassociation.com](https://www.boltassociation.com)

```sh
npm install b017
```
